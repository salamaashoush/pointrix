Snap to Targets drag
Drag
x:0 y:0 snapped:none pivot:
View Code 
import { draggable, snapTargets } from 'pointrix'

// relativePoints controls which point on the element
// is used for snapping:
//   {x:0.5, y:0.5} = center (default in this demo)
//   {x:0, y:0}     = top-left corner
//   {x:1, y:1}     = bottom-right corner
draggable('#snap-el', {
  modifiers: [
    snapTargets({
      coordinateMode: 'parent',
      relativePoints: [{ x: 0.5, y: 0.5 }],
      targets: [
        { x: 60, y: 60 },
        { x: 240, y: 60 },
        ...
      ],
      range: 50
    })
  ]
})

4. Gesture (Multi-touch)

Pinch to zoom and rotate with two fingers or pointers. Use touch or multiple mouse pointers (e.g. dev tools touch emulation).

Pinch / Rotate / Scale gesture
Pinch & Rotate
(use 2 fingers)

View Code 
import { gesturable } from 'pointrix'

let scale = 1, rotation = 0

gesturable('#gesture-el', {
  onGestureMove(e) {
    scale = e.scale
    rotation = e.rotation
    el.style.transform =
      `scale(${scale}) rotate(${rotation}deg)`
  }
})

View Code 
import { draggable, dropzone, DropzoneManager } from 'pointrix'

const zone = dropzone('#dz-warm', {
  accept: (el) => ['red', 'amber'].includes(el.dataset.color),
  activeClass: 'dz-active',
  hoverClass: 'dz-hover',
  onDrop(e) {
    console.log('dropped:', e.draggable)
  }
})

// On drag start, notify DropzoneManager
draggable(card, {
  onDragStart(e) { DropzoneManager.onDragStart(e.target) },
  onDragMove(e) { DropzoneManager.onDragMove(e.target, pointer) },
  onDragEnd(e) { DropzoneManager.onDragEnd(e.target, pointer) }
})
